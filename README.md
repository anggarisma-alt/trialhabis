# Halaman Trial Berakhir

Halaman satu layar (mobile-first, putih) yang memberi tahu masa trial berakhir dan mengarahkan pengguna memilih paket via WhatsApp. Dwibahasa Indonesia/Inggris.

- Frontend: HTML + CSS + JavaScript murni (GitHub Pages)
- Backend: Google Apps Script (REST API JSON) + Google Sheets
- Harga, teks, dan nomor admin diedit di sheet `AppConfig`

Langkah pemasangan lengkap: lihat **PANDUAN-INSTALASI.md**.
